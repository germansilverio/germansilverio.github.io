# Versiones del portfolio

- `v1-ago-2026/` — primera versión publicada (agosto 2026). Diseño propio, CSS y JS a mano,
  bilingüe ES/EN. Incluye las variantes de exploración a / b / c.
- `v2-sep-2026/` — versión actual (septiembre 2026). Diseño "Taller" partido de un borrador de
  Google Stitch, adaptado con las capturas reales de cada proyecto. Es la que se sirve desde
  la raíz del repo (`../index.html`, mismo archivo con rutas relativas a la raíz).

Las imágenes (`assets/`) y la demo de Smart Finance (`demo/`) viven en la raíz y las comparten
todas las versiones.
